# Lendas do Combate

Primeira versão jogável: tela inicial, seleção de personagens, placeholders "Em breve" e luta local para 1 ou 2 jogadores.

## Arquivos
- `index.html`: jogo e interface.
- `fighters.js`: lista única de personagens, imagens e atributos.
- `assets/`: seis retratos enviados.

## Controles
- Jogador 1: A/D andar, W pular, S agachar, F defender, G soco, H golpe forte, T chute, Y especial.
- Jogador 2: setas para mover, J/K/L/; para golpes.
- Celular: vire a tela para a horizontal e use os controles na tela.

## Personalização
Edite `fighters.js` para mudar nome, imagem, cor e atributos. Coloque novas imagens em `assets/` e atualize o caminho no campo `image`.

Abra `index.html` em um navegador moderno ou publique os arquivos em hospedagem estática.
